# Olivia Massiel — letras bordadas WebP

Assets individuales del alfabeto bordado para uso web.

- Mayúsculas: A–Z + Ñ
- Minúsculas: a–z + ñ
- Formato: WebP con transparencia
- Compresión: WebP lossless (sin pérdida)
- Sin fondos visibles
- Sin números ni signos de puntuación
- Cada letra conserva su textura, flores y color del diseño original.
- Se dejó un pequeño margen transparente de seguridad para evitar recortes.

Recomendación de implementación:
usar cada archivo como asset visual y mantener el texto semántico en HTML/ARIA cuando sea necesario.
